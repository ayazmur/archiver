# Архиватор с базой паролей

Небольшая Windows-программа для ZIP-архивов. При распаковке она сначала пробует открыть архив без пароля, затем перебирает пароли из локальной базы. Если ничего не подошло, предлагает ввести пароль вручную и может сохранить его в базу.

## Установка и запуск

Нужен Python 3.10 или новее. В PowerShell откройте эту папку и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python archiver.py
```

## Сборка и GitHub Release

Локальная сборка Windows-приложения:

```powershell
python tools/create_icon.py
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name Archiver --icon assets/app.ico --add-data "assets/app.ico;assets" archiver.py
```

Готовый файл будет в `dist/Archiver.exe`. После публикации репозитория на GitHub создайте и отправьте тег, например `v1.0.0`:

```powershell
git tag v1.0.0
git push origin v1.0.0
```

Workflow `.github/workflows/release.yml` автоматически соберёт `.exe` и прикрепит его к странице GitHub Releases. Его также можно вручную запустить на вкладке **Actions** — в этом случае готовый файл появится в артефактах запуска.

## Что умеет

- Распаковывать обычные ZIP и ZIP с AES-паролем.
- Создавать ZIP и AES-защищённые ZIP.
- Добавлять, изменять и удалять пароли с понятными названиями.
- Не показывает сами пароли в списке.
- Сохраняет базу в `%APPDATA%\PasswordArchiver\passwords.dat`.
- Шифрует всю базу Windows DPAPI: файл можно прочитать только под той же учётной записью Windows.

## Важно

- Это ZIP-архиватор. RAR и 7z здесь намеренно не реализованы: для них нужны отдельные внешние движки и другой способ работы с шифрованием.
- При распаковке приложение не перезаписывает существующие одноимённые файлы в выбранной папке.
- Пароли и архивы остаются на вашем компьютере: приложение никуда их не отправляет.
